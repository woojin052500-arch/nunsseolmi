# 눈썰미

설명은 한 줄, 나머지는 손으로 익히는 디자인 감각 훈련 웹앱입니다. 빌드 없이 `index.html` 하나로 동작합니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 진행 기록은 브라우저 `localStorage`(`nunsseolmi-v2`)에만 저장됩니다.

## 구성

조사 보고서(`docs/research.md`)의 권장 순서를 따라, 정답이 분명한 것에서 눈으로 판단하는 것 순서로 8단계를 배치했습니다.

| 단계 | 내용 | 문항 |
|---|---|---|
| 1. 정렬 | 공유선, 왼쪽 대 가운데 | 4 |
| 2. 간격 | 근접성, 고른 간격, 안쪽 여백, 터치 영역 | 5 |
| 3. 색 기초 | 명도, HSL 명도의 함정, 대비, 비텍스트 대비, 색만으로 말하지 않기 | 6 |
| 4. 위계 | 읽는 순서, 버튼 우선순위, 보조 글자 색, 스퀸트 테스트 | 5 |
| 5. 글자 | 줄 간격, 크기 단계, 제목 행간, 자간, 한글 줄바꿈 | 5 |
| 6. 색 구성 | 60-30-10, 한 색 한 뜻, 색 위의 글자 | 3 |
| 7. 아이콘·형태 | 아이콘 세트 일관성, 모서리, 중첩 모서리, 광학 크기 | 7 |
| 8. 무게중심 | 삼각형 중심, 시각적 중심, 좌우 균형 | 3 |

## 설계 원칙

- **표준과 권장 구분**: 문항마다 기준의 지위를 꼬리표로 표시합니다. 표준은 WCAG 일곱 항목뿐이고, 나머지는 플랫폼 가이드, 권장, 계산값, 지각 연습, 눈으로 판단으로 나눕니다.
- **고른 뒤에 설명**: 대조 쌍을 먼저 보여 주고, 한 문장 이유는 선택 직후에 보여 줍니다.
- **겹쳐 비교**: 둘 중 고르기 문항은 답한 뒤 두 보기를 같은 자리에 겹쳐 번갈아 볼 수 있습니다.
- **세 구간 채점**: 연속값 문항은 통과(90점 이상) · 거의(60점 이상) · 다시로 나눕니다.
- **대비는 반올림하지 않음**: 4.497:1은 4.49:1로 표시하고 미달로 처리합니다.
- **섞어 풀기**: 단계별로 묶어서 익힌 뒤, 전체에서 무작위로 섞어 복습합니다.

허용오차 값은 조사에서 만든 제안값이며, 실제 응답 분포로 보정이 필요합니다. 자세한 근거와 출처는 `docs/research.md`를 참고하세요.

## 광고 (카카오 애드핏)

`index.html`의 `ADFIT` 설정에 자리별 광고 단위 코드를 넣으면 광고가 나옵니다. 코드가 비어 있는 자리는 화면에 나오지 않습니다.

| 자리 | 키 | 크기 |
|---|---|---|
| 화면 하단 고정 띠 | `sticky` | 320×50 |
| 홈 단계 목록 아래 | `home` | 320×100 |
| 단계 결과 화면 | `result` | 300×250 |
| 모든 화면 맨 아래 | `footer` | 320×100 |

- 애드핏에서는 자리마다 광고 단위를 따로 만들고, 위 크기로 맞춰 주세요.
- 주소 끝에 `?ads=preview`를 붙이면 빈 자리를 점선 상자로 미리 볼 수 있습니다.
- 채울 광고가 없으면 그 자리는 자동으로 접힙니다(`data-ad-onfail`).
- 화면이 바뀔 때마다 광고 자리를 새로 만들고, 애드핏 스크립트를 다시 불러옵니다. 문제를 넘길 때는 다시 불러오지 않습니다.
